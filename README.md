# 《赛博封建：续约季》

一套可制作的中文原创叙事经营游戏剧本。舞台为虚构的安资斯坦：自动化充足，授权、信用与生殖来源认证却被少数财团握住。玩家扮演二十九岁的周衡——持有可撤销代理牌照的女子机甲竞技俱乐部老板；她既没有家族，也不无辜。
