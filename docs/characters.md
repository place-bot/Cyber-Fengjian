# 人物与关系

- **周衡，29**：俱乐部“铆钉会”主理人，前机库排程员。爱修旧收音机、会把坏零件按声音分类。初始资金含一次成年来源采集补偿；她擅长算账，也擅长把算账说成照顾。她不是财阀继承人，牌照由岚塔担保。
- **唐梨，27**：队长、重型架驾驶员。安静，讨厌被叫“铁娘子”，擅长用最小动作守住占点；晚上给母亲发语音却从不承认紧张。与许雾相恋，关系并非营业素材。
- **许雾，25**：轻型架、舞台编排能手，笑话多，面对镜头反而会忘词。她想攒钱离开经纪债务，不想被周衡解释成“向上流动样本”。
- **穆莎·卡里姆，31**：技术型中场，维修学徒出身，信奉节制而不接受别人替她定义节制。她会为别人作保，也会精确记得谁没有还钱。
- **韩霁，23**：新人、速度架。成年人职业机构毕业，成绩漂亮，渴望被看见，又厌恶每个“机会”都像价签。
- **罗珊，34**：医疗与合规顾问，合同上是外包。冷硬，实则把每次强制停机记成名字；她知道周衡的来源采集旧档。
- **魏岑，38**：岚塔经纪行代理人。礼貌、从不提高音量，擅长把命令写成“供参考”。
- **杜甫**：四轮机器狗，记账、认门、送零件。不能黑进系统，偶尔在最不合时宜处朗读版权过期旧诗。它只会按周衡设置的权限善良。

关系的中心不是恋爱，而是担保：周衡欠魏岑牌照，队员欠俱乐部排班，俱乐部欠罗珊医疗尾款；唐梨与许雾彼此相爱，却无法替对方签下任何免责条款。叙述不假装知道她们全部内心：可见的是她们如何关门、删讯息、把没吃完的药盒推给彼此。
