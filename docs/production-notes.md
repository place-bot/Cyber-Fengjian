# 演出与制作补充：物件、声音、节奏

本文件补足八关的可执行演出原则。它不是剧情摘要：关卡文件中的每一个选择都应在下一关以一张具体的纸、一句变调的称呼、一项可见的排班限制回到玩家面前。镜头不可把队员当成周衡良心的背景。周衡未在场的短镜头亦可交给唐梨、许雾、穆莎、韩霁或罗珊：她们可以拒绝、误会、相爱、算错钱、对彼此不耐烦；周衡并不拥有解释权。

## 八段过场
**开门后**：黑屏先有扫地机的轮声，后有杜甫撞门。画面亮起时只见一张门禁失败回执。周衡把回执折成四折再塞进口袋；不特写眼泪。唐梨从画外问：“卡呢？”这比任何自白更早交代权力：钥匙属于系统，系统不需要恨她。

**评级后**：镜头停在韩霁的海报渲染图。系统自动磨平她脸上的疲惫，渲染完毕后她从画面左侧走过，真人与图像不同步。许雾把图反扣，随后又翻回来，因为她也知道点击量能付电费。这个动作不奖励，也不惩罚；它只被唐梨看见。

**首分后**：赛馆的排名屏上数字缓慢上升，后台的热敏结算单则快速吐出扣款。声音设计令欢呼与打印机同拍。周衡撕不掉扣款单，纸纤维反而把“稳定费”撕得更清楚。罗珊把一张停机警示贴在机库门框，贴歪了；她不重贴。

**私席后**：走廊尽头门合上，镜头留在门外的周衡和罗珊，绝不进入私人活动。只播放空调、鞋跟和服务铃。过场末尾，周衡收到一条“满意度待确认”的自动消息；她删不掉，只能标为已读。若玩家拒绝附件，则相同走廊的灯熄一半，表现被取消的时段，而非把拒绝拍成胜利。

**停机后**：唐梨的机甲被空吊架吊起，吊带缓慢转动。许雾试图为它贴一张滑稽贴纸，贴到一半又撕下。医疗隔间只呈现门牌、药盒外观、恢复排程和等待，不呈现医疗操作。若周衡选择自身来源补偿融资，则日历上出现恢复日，玩家只能安排她远程签字，不能把她的身体变成资源小游戏。

**窗口后**：便利店微波炉转完，韩霁的转会提示也转完。两者同时发出提示音。唐梨与许雾不为镜头接吻或分手；她们只是错过了对方递来的纸巾。选择拆散她们的宣传组合可能提高某项商业评分，却不会判定关系真假；关系不是可结算的附属模块。

**年展后**：通行证在楼层间更新颜色，从灰到白。每上一层，背景噪音少一层，直到顶层安静得能听见衣料摩擦。周衡的拒绝没有英雄配乐，只造成工作人员更礼貌地请她离开主会场。杜甫错误朗读被观众剪成梗图，屏幕角落显示播放量；角色没有因此突然走红。

**续约后**：结局保持长镜头。三种经营状态都让同一张桌子存在，只是桌上留下的合同数不同。续住时灯仍坏；被收编时岚塔员工把“铆钉会”标牌装箱；散场时周衡把轴承放进普通塑料袋。收租铃响两次，切黑。不要显示“改变世界”的统计。

## 声音、道具与用词表
机甲声音应区分为液压低鸣、轴承砂响、功率锁提示和安全停机的三短一长；不要使用枪炮或战场音效。合同纸张有克重：岚塔附件厚、联盟回执薄、工资条易卷边。杜甫的朗读每关最多一次，且总能被一个人打断；它是记忆的笨拙容器，不是预言家。

词汇避免“征服”“歼灭”“战役”。比赛说“回合、占点、判罚、停机、席位”；商业说“账期、担保、排他、授权、回执”。私军只可在远处新闻滚条上作为就业广告或保安合同背景，绝不出现作战、清剿或护送玩法。

## 分支验收清单
- 原厂件应在首分赛减少故障判定；翻新件必须出现声音、工单或停机代价。
- 人设选择在私席中改变报价，但不得强迫任何角色接受私人劳务。
- 私席合同的资料共享在医疗章以回执、删除请求或保险扣款回收。
- 停机优先会压缩年展席位；带伤不应被写作壮烈，而应由罗珊强制止损。
- 转会和担保签名须在续约桌上显示谁承担何笔钱；不得用“大家原谅了”跳过。
- 三结局均保留一个无用物件：轴承、梅核纸或收音机杂音。它们不兑换资源。

## 叙事镜头权限
玩家可阅读合同、查看账目、安排公开训练与合规商务；玩家不能指挥私人随行、窥看医疗细节、强制角色表演亲密关系，亦不能以“服从值”获得任何好处。若队员拒绝，界面应显示具体损失（场次、钱、牌照压力），同时保留拒绝本身，不把其变成周衡的道德奖励。人物的沉默可不被解释：屏幕只显示“未回复”，而不是替她们写出心声。
