# 第三关：首次计分赛

**时间地点：** 春三月，环线一号馆，19:00
**目标：** 在安全规则内拿到首个积分，决定是否为排名冒险。
**机制：** 回合制占点；功率、暂停、技术动作；胜负不以击毁计。

## 场景一
场馆像一只昂贵的空壳，观众的欢呼从壳里滚出来。裁判宣布：“接触阈值六十，越线自动停机。”周衡在控制台看见唐梨的重架守住蓝点，像一扇有耐心的门。许雾在耳机里说：“老板，我要不要做那个旋转？”周衡说：“看轴承。”许雾笑：“终于有人承认我是零件。”

## 场景二
第二回合，翻新轴承发出细响。穆莎报数：“三、二——”周衡有权申请暂停，会丢占点。魏岑发来文字：*首分比维修单更能融资。* 唐梨却说：“我还能站。”罗珊切进频道：“能站不是医学词。”

## 场景三
韩霁冲到镜头前，完成漂亮的跃步，随即被系统判姿态超限。她摘下头盔：“我是不是把你们的第一分卖掉了？”许雾递水给她：“没有。你只是把它借给了明天。”唐梨补一句：“明天也会收利息。”周衡听见她们说话，知道这不是给自己听的。

## 场景四
赛后结算机吐出奖金条，平台先扣了“观赛稳定费”。周衡把纸条塞进杜甫背包。杜甫说：“白头搔更短。”周衡回：“别念了，短的是账期。”

## 场景五：论第一分
第一分不像钱。钱会被扣走，第一分则被放在排行榜上，供陌生人抚摸、辱骂、截图；它甚至比钱更适合让人误以为自己被看见。赛后一个少年粉丝隔着护栏喊唐梨“妈妈”，唐梨停了半秒才说：“我不是。”工作人员已经把这一段剪成可爱的短片。周衡可以要求下架，却知道投诉会进入与房租同一个缓慢的队列。

后台，韩霁把判罚单折成很小的方块。周衡问要不要申诉。韩霁说：“申诉会改分吗？”“不一定。”“那你为什么问？”周衡答：“因为这是我能给的程序。”韩霁把纸塞回她手里：“程序留给你。我要回去练。”这不是服从，更不是原谅；只是有人今晚仍要赶末班车。

## 制作注记：候场室的时间
候场室的钟总比场馆慢两分钟。它并非故障，而是旧租户留下的习惯：让等候的人以为自己尚有一点时间。周衡知道这一点，仍没有校正。她在这里逐项核对工单、过敏申报、交通补贴、未读回执和每个人是否已吃饭；这些小事没有一件能被剪进宣传片，却比“团队精神”更常决定谁能在下一轮站稳。

“你又在数什么？”有人问。

“数还能补的洞。”周衡说。

“那数完呢？”

“数完再决定哪一个先漏。”

这回答很像老板，也很像一个从未被允许浪费的人。没有人因此感谢她。有人去接水，有人把头盔扣上，有人把一句原本要说的责备留到赛后。杜甫沿墙巡逻，轮子碾过胶带边缘，发出细小的、几乎可被忽略的声响。周衡记住了它；维修记录不记。
