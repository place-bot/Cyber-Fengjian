# UI、美术与叙事设计规范

## 总则
老式经营模拟与机库管理界面：低饱和灰绿、褪色米白、油污黑；宋体/黑体分层，窄列账本、直角细边框、纸质登记表与热敏回执。避免渐变、玻璃卡、大圆角、无意义霓虹。叙事长句只在旁白/物件说明；按钮短促：`暂停`、`签署`、`拒绝`、`查看扣款`。

## 六屏线框与文案
1. **赛历**：左侧周历/馆名/时段；右侧“通行证等级｜功率上限｜预计回款”。提示：`馆租将在 2 日后自动扣除。`
2. **队员档案**：顶部姓名、年龄（均 21+）、岗位、停机状态；中部合同与个人偏好；底部：`不要把已知事项当成她的全部。`
3. **赛事调度**：机位格、替补、轴承序列、裁判规则；红条：`接触阈值 60／自动停机有效。`
4. **合同**：双栏原文与白话风险；高亮“数据留存”“不得无故离席”；按钮：`要求删改`、`拒绝附件`、`签署并存档`。
5. **维修**：部件图、原厂/翻新/无件三列，保单期限与异响日志。杜甫提示：`发现圆形金属，价值待定。`
6. **结算**：奖金、平台抽成、医保、房租、工资逐行列出，最后一行：`可用现金不是尊严。`

关键叙事只在回执、候场室门牌、已读未回、工单的错误姓名上出现；不给角色加“好感度心形”，仅显示信任、身体余量与可撤销权限。
