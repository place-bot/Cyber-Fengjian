# 经营变量与分支衔接

|变量|范围|含义|高/低的代价|
|---|---:|---|---|
|现金 C|0–100|房租、工资、维修与垫资|低于0触发催收；高现金多来自不可逆让步|
|牌照 L|0–5|岚塔担保与联盟准入|低则减少赛程；高则接受更多审查|
|队伍信任 T|0–5|队员愿否透露风险、留下续约|低则失误与转会；高不等于原谅|
|身体余量 B|0–5|伤病、疲劳与恢复资源|低会被医疗强制停机|
|声誉 R|0–5|粉丝、排名、品牌意愿|高会增加窥视与商业压力|

**初始：C3/L2/T2/B4/R1。** 每章选择明确增减；不以道德分数结算。章节回收：01 的原厂轴承影响03；02 的人设决定04私席价；03 的排名决定06报价；04 的保密条款在05医疗回执出现；05 的停机决定07席位；06 的担保签名决定08谁可续约。结局按 C、L、T 与谁仍有合同决定：**续住（C≥2,L≥2,T≥3）**、**被收编（L≥3,T≤2）**、**散场清算（C≤0或L=0）**。三者都不推翻制度。
